# Presentación ejecutiva — Howy

**Tema:** Aplicaciones e IAs para crear, generar y editar video — fáciles de usar, gratuitas o de bajo costo y con conexión a IA.

## Archivos
- `Howy_Herramientas_IA_Video_2026.pptx` — Presentación final (PowerPoint, 16:9, 13 diapositivas).
- `generar_presentacion.py` — Script que genera el `.pptx` (python-pptx).

## Contenido (13 diapositivas)
1. Portada
2. Resumen ejecutivo
3. Metodología y criterios de evaluación
4. Panorama: el ecosistema en 5 categorías
5. Generación de video con IA (Kling, Veo, Runway, Pika/Luma)
6. Edición con IA (CapCut, Descript, DaVinci Resolve, Premiere)
7. Avatares con IA (HeyGen, Synthesia)
8. Todo-en-uno / guion→video (Pictory, InVideo, VEED, Canva)
9. Automatización y conexión con IA (OpusClip, Shotstack, Fliki, Manus)
10. Tabla comparativa de costo y facilidad
11. Recomendaciones por perfil
12. Conclusiones y próximos pasos
13. Cierre

## Cómo regenerar
```bash
pip install python-pptx
python3 generar_presentacion.py
```
